- 🎧 **最高音质录制**：无损音质 / 超清全景声 / 录音室音质（SIVP）可选，本地保存原始文件。
- 🎼 **任选录制格式**：320K MP3 / FLAC / WAV 三种格式随需切换，适配听歌、剪辑、母带存档等不同用途。
- 📦 **批量自动录制**：整张歌单、整个专辑一键排队，挂机就能全部录完。
- 🖱️ **上手极简**：打开软件 → 连接汽水音乐 → 点开始，无需命令行、无需配置。
- 🪟 **兼容 Windows 7 / 10 / 11**：分别提供两个安装包，普通用户双击下一步即可完成安装。
- 🔄 **持续更新**：紧随汽水音乐客户端升级，保持稳定录制。

## 🔊 录制音质注意事项

> **请将「汽水音乐客户端音量」和「Windows 系统声音音量」都开到最大**，否则容易出现录制波形声音音量过小、成品听起来发闷的情况。母带的响度取决于源头音量，软件不会额外拉伸，避免二次压缩造成音质损失。

### 首次使用 3 步走
1. 双击安装包，按默认「下一步」完成安装。
2. 打开桌面「涨停吧汽水音乐录制工具」，注册 / 登录账号。
3. 在软件里粘贴歌单或选中歌曲，选择音质与格式（320K MP3 / FLAC / WAV），点「开始录制」，等待完成即可在输出目录看到高音质音频。

## 🆘 常见问题

- **Q：录制的音质怎么选？** A：默认使用 SIVP / 无损 / 超清全景声中官方开放的最高级别，可以在设置里手动切换；输出格式支持 320K MP3 / FLAC / WAV。
- **Q：录出来的歌声音太小？** A：请把汽水音乐客户端音量条和 Windows 系统音量都调到最大再录，避免波形本身太小。
- **Q：Windows SmartScreen 提示未识别？** A：点「更多信息 → 仍要运行」即可，属于新版安装包尚未积累声誉的正常现象。
- **Q：录制失败 / 授权异常？** A：请先确认已登录账号，检查网络连接后重启软件；如仍有问题，请到 [Issues](../../issues) 反馈。
